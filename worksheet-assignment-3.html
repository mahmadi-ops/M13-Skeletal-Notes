    Worksheet 4.3 Assignment 3
    

    These problems bound the error in a Taylor approximation with the Remainder Theorem and use Taylor series to compute limits and integrals. Problems marked with a star (\(*\)) are for the interested reader: they do not need to be handed in and will not be examined. If you would like to review the material first, see Taylor Series and its convergence.
    🔗

    1.

    For approximately what values of \(x\) can we replace \(\sin(x)\) by \(x - \dfrac{x^3}{6}\) with an error of magnitude no greater than \(4 \times 10^{-3}\text{?}\)
    🔗
    Solution.
    Here \(a = 0\text{,}\) and the cubic \(x - \dfrac{x^3}{3!}\) is \(T_3(x)\text{.}\) But the Maclaurin series of \(\sin\) has no \(x^4\) term, so the same polynomial is also the fourth order Taylor polynomial:
    \begin{align*} T_4(x) \amp = x - \frac{x^3}{3!} + \frac{f^{(4)}(0)}{4!}x^4\\ \amp = x - \frac{x^3}{3!} = T_3(x), \qquad\text{since } f^{(4)}(0) = \sin(0) = 0 . \end{align*}
    We should therefore take \(n = 4\text{,}\) not \(n = 3\text{:}\) both choices describe the very same approximation, but the remainder \(R_4\) is one order smaller than \(R_3\) and so gives the sharper estimate.
    🔗
    The derivatives of \(f(x) = \sin(x)\) are
    \begin{align*} f'(x) \amp = \cos(x), \amp f''(x) \amp = -\sin(x),\\ f^{(3)}(x) \amp = -\cos(x), \amp f^{(4)}(x) \amp = \sin(x),\\ f^{(5)}(x) \amp = \cos(x), \amp \amp \end{align*}
    and therefore \(\left|f^{(5)}(c)\right| = |\cos(c)| \le 1\text{,}\) so we can take \(M = 1\text{.}\)
    🔗
    By the Remainder Theorem with \(n = 4\text{,}\)
    \begin{equation*} \text{Error} = |R_4(x)| \le M\,\frac{|x-a|^5}{5!} = \frac{|x|^5}{5!} \le 4\times 10^{-3}, \end{equation*}
    which gives
    \begin{align*} |x| \amp \le \sqrt[5]{(5!)(0.004)} = \sqrt[5]{0.48} \approx 0.863,\\ \amp \Rightarrow\quad x \in [-0.863,\; 0.863]. \end{align*}
    See Figure 4.3.1.
    🔗
    For comparison, stopping at \(n = 3\) would have given \(|x| \le \sqrt[4]{(4!)(0.004)} \approx 0.556\text{,}\) a needlessly small interval for exactly the same polynomial.
    🔗

    2.

    Use the remainder estimation theorem to estimate the maximum error when approximating \(f(x) = e^x\) by \(T_2(x) = 1 + x + \dfrac{x^2}{2}\) on the interval \(\left[-\dfrac56, \dfrac56\right]\text{.}\)
    🔗
    Solution.
    From the remainder theorem, we know that
    \begin{equation*} \text{Error} = |R_2(x)| = \left|\frac{f^{(3)}(c)}{3!}\,x^3\right| \le \frac{e^c}{3!}\,|x|^3. \end{equation*}
    🔗
    Also, since \(c \in \left[-\frac56, \frac56\right]\text{,}\) we have \(|c| \le \frac56\) and hence \(e^c \le e^{5/6}\text{:}\)
    \begin{equation*} \text{Error} = |R_2(x)| \le \frac{e^{5/6}}{3!}\left(\frac56\right)^{3}. \end{equation*}
    🔗
    We know that \(e^{5/6} \lt e^1 \lt 3\text{,}\) hence
    \begin{equation*} \text{Error} = |R_2(x)| \le \frac{e^{5/6}}{3!}\left(\frac56\right)^{3} \lt \frac{3}{3!}\left(\frac56\right)^{3} \approx 0.289. \end{equation*}
    Hence, an estimate for the upper bound of the error is \(\dfrac{3}{3!}\left(\dfrac56\right)^{3} \approx 0.289\text{.}\) See Figure 4.3.2.
    🔗

    3.

    Consider the function \(f(x) = \ln(1 + 2x)\text{.}\)
    1. Find the second order Taylor polynomial \(T_2(x)\) centered at 0.
      🔗
      🔗
    2. Estimate the maximum error when approximating \(f(x) = \ln(1+2x)\) with the second order Taylor polynomial \(T_2(x)\) centered at 0, on the interval \([-0.25, 0.25]\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. We compute the derivatives at 0:
      \begin{align*} f'(x) \amp = \frac{2}{1+2x} = 2(1+2x)^{-1}, \amp f'(0) \amp = 2,\\ f''(x) \amp = -4(1+2x)^{-2}, \amp f''(0) \amp = -4. \end{align*}
      Hence
      \begin{equation*} T_2(x) = f(0) + f'(0)(x-0) + \frac{f''(0)}{2!}(x-0)^2 = 0 + 2x - 2x^2, \end{equation*}
      i.e. \(T_2(x) = 2x - 2x^2\text{.}\)
      🔗
      🔗
    2. We have \(f^{(3)}(x) = 16(1+2x)^{-3}\) and \(-\frac14 \le x \le \frac14\text{.}\) Note that \(f^{(4)}(x) = -96(1+2x)^{-4}\) is negative, which means \(f^{(3)}\) is a decreasing function, hence at \(x = -\frac14\) the value \(f^{(3)}(c)\) is maximized, i.e.,
      \begin{equation*} f^{(3)}(c) \le f^{(3)}(-0.25) = 16\left(1 - \frac12\right)^{-3} = 128. \end{equation*}
      Also
      \begin{equation*} -\frac14 \le x \le \frac14 \;\Rightarrow\; |x^3| \le \left(\frac14\right)^{3} = \frac{1}{4^3} = \frac{1}{64}, \end{equation*}
      and therefore
      \begin{equation*} \text{Error} = |R_2(x)| \le \left|\frac{f^{(3)}(c)}{3!}\,x^3\right| \le \frac{1}{3!}\cdot\frac{1}{64}\cdot 128 = \frac13. \end{equation*}
      This means that the error in estimating \(f(x) = \ln(1+2x)\) for \(-\frac14 \le x \le \frac14\) by \(T_2(x) = 2x - 2x^2\) is definitely smaller than \(\frac13\text{.}\) See Figure 4.3.3.

    4.

    Let
    \begin{align*} f(x) \amp = 1 + 2x + 3x^2\\ \amp \quad + 4x^3 + 5x^4 + \cdots \end{align*}
    Find the exact value of \(\displaystyle\int_0^{1/13} f(x)\,dx\text{.}\)
    🔗
    Solution.
    First we identify \(f\text{.}\) Its general term is \((n+1)x^n\text{,}\) so
    \begin{equation*} f(x) = \sum_{n=0}^{\infty} (n+1)x^n . \end{equation*}
    This is exactly what you get by differentiating the geometric series term by term:
    \begin{align*} \frac{1}{1-x} \amp = \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots , \qquad |x| \lt 1,\\ \frac{d}{dx}\left(\frac{1}{1-x}\right) \amp = \frac{1}{(1-x)^2} = \sum_{n=1}^{\infty} n x^{n-1} = 1 + 2x + 3x^2 + \cdots \end{align*}
    So \(f(x) = \dfrac{1}{(1-x)^2}\) for \(|x| \lt 1\text{.}\) Since \(\tfrac1{13} \lt 1\text{,}\) the whole interval of integration lies inside the interval of convergence.
    🔗
    Now we integrate. An antiderivative of \((1-x)^{-2}\) is \((1-x)^{-1}\text{,}\) so
    \begin{align*} \int_0^{1/13} \frac{dx}{(1-x)^2} \amp = \left[\frac{1}{1-x}\right]_0^{1/13}\\ \amp = \frac{1}{1-\frac{1}{13}} - \frac{1}{1-0}\\ \amp = \frac{1}{\frac{12}{13}} - 1 = \frac{13}{12} - 1 = \frac{1}{12} . \end{align*}
    🔗
    🔗

    5.

    Evaluate \(\displaystyle\int \frac{\cos x - 1}{x}\,dx\) as an infinite series. Give the first three nonzero terms.
    🔗
    Solution.
    The integrand has no elementary antiderivative, so expand it as a series first. Starting from \(\cos x = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dfrac{x^6}{6!} + \cdots\text{,}\) subtracting \(1\) kills the constant term, so every surviving power of \(x\) is even and at least \(2\text{.}\) Dividing by \(x\) therefore leaves an honest power series:
    \begin{align*} \frac{\cos x - 1}{x} \amp = \frac{1}{x}\left(-\frac{x^2}{2!} + \frac{x^4}{4!} - \frac{x^6}{6!} + \cdots\right)\\ \amp = -\frac{x}{2!} + \frac{x^3}{4!} - \frac{x^5}{6!} + \cdots \end{align*}
    🔗
    Integrating term by term,
    \begin{align*} \int \frac{\cos x - 1}{x}\,dx \amp = C - \frac{x^2}{2\cdot 2!} + \frac{x^4}{4\cdot 4!} - \frac{x^6}{6\cdot 6!} + \cdots\\ \amp = C - \frac{x^2}{4} + \frac{x^4}{96} - \frac{x^6}{4320} + \cdots \end{align*}
    🔗
    🔗

    6.

    Use Taylor series to evaluate
    \begin{equation*} \lim_{x\to 0} \frac{\cos(2x) - 1}{x^2 e^{x}} . \end{equation*}
    🔗
    Solution.
    The quotient has the indeterminate form \(\frac00\text{.}\) Replace the numerator and the denominator by their Maclaurin series. Putting \(2x\) in place of \(x\) in \(\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\text{,}\)
    \begin{align*} \cos(2x) \amp = 1 - \frac{(2x)^2}{2!} + \frac{(2x)^4}{4!} - \cdots = 1 - 2x^2 + \frac{2}{3}x^4 - \cdots\\ \Rightarrow\quad \cos(2x) - 1 \amp = -2x^2 + \frac{2}{3}x^4 - \cdots \end{align*}
    and from \(e^{x} = 1 + x + \frac{x^2}{2!} + \cdots\text{,}\)
    \begin{equation*} x^2 e^{x} = x^2\left(1 + x + \frac{x^2}{2!} + \cdots\right) = x^2 + x^3 + \frac{x^4}{2} + \cdots . \end{equation*}
    🔗
    Both vanish to exactly second order, so cancel the common factor of \(x^2\) — legitimate, since the limit never uses the value at \(x = 0\) itself:
    \begin{align*} \lim_{x\to 0} \frac{\cos(2x) - 1}{x^2 e^{x}} \amp = \lim_{x\to 0} \frac{x^2\left(-2 + \frac{2}{3}x^2 - \cdots\right)} {x^2\left(1 + x + \frac{x^2}{2!} + \cdots\right)}\\ \amp = \lim_{x\to 0} \frac{-2 + \frac{2}{3}x^2 - \cdots} {1 + x + \frac{x^2}{2!} + \cdots} = \frac{-2}{1} = -2 . \end{align*}
    Each remaining series is continuous at \(0\) with a nonzero value there, so only the two leading coefficients matter.

    7.

    Show that
    \begin{equation*} \int_0^1 \frac{\sin(\ln t)}{\ln t}\,dt = \frac{\pi}{4}. \end{equation*}
    (The integrand is continuous on \((0,1)\text{.}\) As \(t \to 1^-\) we have \(\ln t \to 0\text{,}\) so the integrand tends to \(1\text{;}\) as \(t \to 0^+\) we have \(\left|\dfrac{\sin(\ln t)}{\ln t}\right| \le \dfrac{1}{|\ln t|} \to 0\text{.}\) So the integrand is bounded and the integral exists. Its antiderivative is not elementary.)
    🔗
    Hint.
    Two facts from Calculus II, both proved by integration by parts
     1 
    For \(I_k\text{:}\) \(I_0 = \int_0^{\infty} e^{-x}\,dx = 1\text{,}\) and for \(k \ge 1\) integration by parts with \(u = x^k\) and \(dv = e^{-x}\,dx\) gives \(I_k = \Big[-x^k e^{-x}\Big]_0^{\infty} + k\,I_{k-1} = k\,I_{k-1}\text{,}\) since \(x^k e^{-x} \to 0\) as \(x \to \infty\text{;}\) by induction \(I_k = k!\text{.}\) For \(J_k\text{:}\) \(J_0 = 1\text{,}\) and for \(k \ge 1\) integration by parts with \(u = (\ln t)^k\) and \(dv = dt\text{,}\) so \(du = k(\ln t)^{k-1}\,\frac{dt}{t}\) and \(v = t\text{,}\) gives \(J_k = \Big[t(\ln t)^k\Big]_0^1 - k\,J_{k-1} = -k\,J_{k-1}\text{.}\) The bracket vanishes at \(t = 1\) because \(\ln 1 = 0\text{,}\) and at \(t = 0^+\) because \(t(\ln t)^k \to 0\) (by L’Hôpital’s rule). By induction, \(J_k = (-k)(-(k-1))\cdots(-1)\,J_0 = (-1)^k k!\text{.}\)
    : for every integer \(k \ge 0\text{,}\)
    \begin{align*} I_k \amp = \int_0^{\infty} x^k e^{-x}\,dx = k!,\\ J_k \amp = \int_0^1 (\ln t)^k\,dt = (-1)^k\,k!. \end{align*}
    Either substitute \(t = e^{-x}\) and use Example 2.3.19, or expand \(\dfrac{\sin(\ln t)}{\ln t}\) as a series in \(\ln t\) and integrate term by term with \(J_k\text{.}\)
    🔗
    🔗
    Solution.
    Solution 1 (substitution). Let \(t = e^{-x}\text{,}\) so \(x = -\ln t\) and \(dt = -e^{-x}\,dx\text{.}\) As \(t\) runs from \(0\) to \(1\text{,}\) \(x\) runs from \(\infty\) to \(0\text{.}\) Since \(\ln t = -x\text{,}\)
    \begin{equation*} \frac{\sin(\ln t)}{\ln t} = \frac{\sin(-x)}{-x} = \frac{\sin x}{x}. \end{equation*}
    Therefore
    \begin{align*} \int_0^1 \frac{\sin(\ln t)}{\ln t}\,dt \amp = \int_{\infty}^{0} \frac{\sin x}{x}\,\left(-e^{-x}\right)dx\\ \amp = \int_0^{\infty} e^{-x}\,\frac{\sin x}{x}\,dx = \frac{\pi}{4} \end{align*}
    by Example 2.3.19.
    🔗
    Solution 2 (directly with series). Substituting \(u = \ln t\) into the series \(\dfrac{\sin u}{u} = \displaystyle\sum_{n=0}^{\infty} \frac{(-1)^n u^{2n}}{(2n+1)!}\text{,}\)
    \begin{equation*} \frac{\sin(\ln t)}{\ln t} = \sum_{n=0}^{\infty} \frac{(-1)^n (\ln t)^{2n}}{(2n+1)!}. \end{equation*}
    Integrating term by term and using \(J_k\) with \(k = 2n\) (so \((-1)^{2n} = 1\)),
    \begin{align*} \int_0^1 \frac{\sin(\ln t)}{\ln t}\,dt \amp = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!}\,(2n)!\\ \amp = \sum_{n=0}^{\infty} \frac{(-1)^n}{2n+1} = \arctan 1 = \frac{\pi}{4}. \end{align*}
    🔗
    Justification. With \(S_N(x) = \displaystyle\sum_{n=0}^{N} \frac{(-1)^n x^{2n}}{(2n+1)!}\text{,}\) the Remainder Estimation Theorem gives \(\left|\dfrac{\sin x}{x} - S_N(x)\right| \le \dfrac{x^{2N+2}}{(2N+3)!}\text{,}\) exactly as in Example 2.3.19. Replacing \(x\) by \(u = \ln t\text{,}\)
    \begin{equation*} \left|\frac{\sin(\ln t)}{\ln t} - S_N(\ln t)\right| \le \frac{(\ln t)^{2N+2}}{(2N+3)!}. \end{equation*}
    Integrating over \([0,1]\) with \(J_k\text{,}\) \(k = 2N+2\text{,}\) bounds the error after \(N+1\) terms by
    \begin{equation*} \frac{(2N+2)!}{(2N+3)!} = \frac{1}{2N+3} \longrightarrow 0, \end{equation*}
    so the partial sums converge to the integral, and the integral equals \(\pi/4\text{.}\)
