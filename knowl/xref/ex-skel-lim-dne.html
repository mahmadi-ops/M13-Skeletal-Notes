Example 4.2.5. A Limit That Does Not Exist.

Consider the function \(f(x,y) = \dfrac{xy}{x^2+y^2}\text{.}\) Does \(\lim_{(x,y)\to(0,0)} f(x,y)\) exist?
🔗
Solution. (Substituting gives \(0/0\text{,}\) so approach along the three paths drawn in Figure 4.2.6 instead. Restrict \(f\) to each path first — along \(y=0\) it becomes a function of \(x\) alone — and notice that each restriction is constant, so no limit needs taking. Then apply the test you wrote down above.)
