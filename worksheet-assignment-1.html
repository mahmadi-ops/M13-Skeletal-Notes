    Worksheet 3.1 Assignment 1
    

    These problems exercise the hyperbolic identities, the derivatives of the hyperbolic functions and the inverse hyperbolic functions. If you would like to review the material first, see Hyperbolic Functions.
    🔗

    1.

    Show that \(\tanh^2(x) + \operatorname{sech}^2(x) = 1\text{,}\) for all real numbers \(x\text{.}\)
    🔗
    Solution.
    We write both terms over the common denominator \(\cosh^2(x)\) and use the identity \(\cosh^2(x) - \sinh^2(x) = 1\text{,}\) i.e. \(\sinh^2(x) + 1 = \cosh^2(x)\text{:}\)
    \begin{align*} \tanh^2(x) + \operatorname{sech}^2(x) \amp = \frac{\sinh^2(x)}{\cosh^2(x)} + \frac{1}{\cosh^2(x)}\\ \amp = \frac{\sinh^2(x) + 1}{\cosh^2(x)} = \frac{\cosh^2(x)}{\cosh^2(x)} = 1. \end{align*}
    Note that this is valid for every real \(x\text{,}\) since \(\cosh(x) \ge 1 \gt 0\) and so the denominator is never zero.
    🔗
    🔗
    🔗

    2.

    Compute \(\dfrac{d}{dx}\,3\sinh\!\left(\dfrac{3}{x}\right)\text{.}\)
    🔗
    Solution.
    We use \(\dfrac{d}{dx}\sinh(u) = \cosh(u)\,\dfrac{du}{dx}\) with \(u = \dfrac{3}{x} = 3x^{-1}\text{,}\) so \(\dfrac{du}{dx} = -3x^{-2} = -\dfrac{3}{x^2}\text{.}\) Hence
    \begin{equation*} \frac{d}{dx}\,3\sinh\!\left(\frac3x\right) = 3\cosh\!\left(\frac3x\right)\left(-\frac{3}{x^2}\right) = -\frac{9}{x^2}\cosh\!\left(\frac3x\right). \end{equation*}
    🔗
    🔗
    🔗

    3.

    Simplify \(\cosh(\ln 2)\text{.}\)
    🔗
    Solution.
    Using the definition \(\cosh x = \dfrac{e^x + e^{-x}}{2}\) together with \(e^{\ln 2} = 2\) and \(e^{-\ln 2} = \dfrac{1}{e^{\ln 2}} = \dfrac12\text{,}\)
    \begin{equation*} \cosh(\ln 2) = \frac{e^{\ln 2} + e^{-\ln 2}}{2} = \frac{2 + \frac12}{2} = \frac{\frac52}{2} = \frac54. \end{equation*}
    🔗
    🔗
    🔗

    4.

    Solve the equation \(5\sinh(x) - 3\cosh(x) = 3\) for \(x\text{.}\)
    🔗
    Solution.
    We first replace the hyperbolic functions by their definitions:
    \begin{align*} 5\sinh(x) - 3\cosh(x) \amp = 3\\ \Rightarrow\quad \frac{5\left(e^x - e^{-x}\right)}{2} - \frac{3\left(e^x + e^{-x}\right)}{2} \amp = 3\\ \Rightarrow\quad e^x - 4e^{-x} \amp = 3. \end{align*}
    🔗
    Multiplying through by \(e^x\) and writing \(u = e^x\) turns this into a quadratic equation:
    \begin{align*} u^2 - 3u - 4 \amp = 0\\ \Rightarrow\quad (u-4)(u+1) \amp = 0. \end{align*}
    🔗
    Since \(u = e^x\) is positive, the root \(u = -1\) is impossible, and only \(u = 4\) survives. Therefore
    \begin{equation*} e^x = 4 \quad\Longrightarrow\quad x = \ln 4 = 2\ln 2. \end{equation*}
    🔗
    🔗
    🔗

    5.

    Following the method of Example 1.4.2, show that the inverse hyperbolic tangent is given by
    \begin{equation*} \tanh^{-1}(x) = \frac12\ln\left(\frac{1+x}{1-x}\right), \qquad -1 \lt x \lt 1. \end{equation*}
    🔗
    Solution.
    Unlike \(\cosh\text{,}\) the function \(\tanh\) is increasing on all of \(\R\text{,}\) so no restriction of its domain is needed. Set \(y = \tanh(x)\) and solve for \(x\text{.}\) Multiplying the numerator and the denominator by \(e^{x}\) gives
    \begin{equation*} y = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}}\cdot\frac{e^{x}}{e^{x}} = \frac{e^{2x} - 1}{e^{2x} + 1}. \end{equation*}
    🔗
    Writing \(u = e^{2x}\) and clearing the denominator,
    \begin{align*} y(u+1) \amp = u - 1\\ \Rightarrow\quad y + 1 \amp = u - yu = u(1-y)\\ \Rightarrow\quad u \amp = \frac{1+y}{1-y}. \end{align*}
    🔗
    Therefore \(e^{2x} = \dfrac{1+y}{1-y}\text{,}\) and taking the natural logarithm gives \(2x = \ln\left(\frac{1+y}{1-y}\right)\text{.}\) Interchanging the names of the two variables, so that \(y = \tanh^{-1}(x)\) is the inverse function,
    \begin{equation*} y = \tanh^{-1}(x) = \frac12\ln\left(\frac{1+x}{1-x}\right). \end{equation*}
    The range of \(\tanh\) is the interval \((-1,1)\text{,}\) which is exactly the set of \(x\) for which \(\frac{1+x}{1-x}\) is positive, so this is the domain of \(\tanh^{-1}\text{.}\)
    🔗
    🔗
    🔗

    6.

    Use the substitution \(x = \tanh(t)\) to calculate
    \begin{equation*} \int \frac{dx}{1-x^2}, \qquad -1 \lt x \lt 1, \end{equation*}
    and then use Worksheet Exercise 3.1.5 to write your answer with a logarithm. Hint: \(\frac{d}{dt}\tanh(t) = \operatorname{sech}^2(t)\text{,}\) and \(1 - \tanh^2(t) = \operatorname{sech}^2(t)\text{.}\)
    🔗
    Solution.
    With \(x = \tanh(t)\) we have \(dx = \operatorname{sech}^2(t)\,dt\text{,}\) and the denominator collapses by the identity in the hint:
    \begin{align*} \int \frac{dx}{1-x^2} \amp = \int \frac{\operatorname{sech}^2(t)}{1-\tanh^2(t)}\,dt\\ \amp = \int \frac{\operatorname{sech}^2(t)}{\operatorname{sech}^2(t)}\,dt\\ \amp = \int dt = t + C. \end{align*}
    🔗
    Since \(x = \tanh(t)\) means \(t = \tanh^{-1}(x)\text{,}\) and using Worksheet Exercise 3.1.5 to rewrite the inverse function,
    \begin{align*} \int \frac{dx}{1-x^2} \amp = \tanh^{-1}(x) + C\\ \amp = \frac12\ln\left(\frac{1+x}{1-x}\right) + C. \end{align*}
    This agrees with the answer obtained by partial fractions, since \(\frac12\ln\left(\frac{1+x}{1-x}\right) = \frac12\ln(1+x) - \frac12\ln(1-x)\text{.}\)
